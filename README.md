# 福伴机器人 Demo

## 项目简介

**福伴机器人**是一款面向独居/空巢老人的 AI 健康生活陪伴机器人 Demo，围绕老年人的 **三餐饮食、购物导航、健康友好路线规划、家属安心反馈** 四个核心场景展开。

项目希望解决的问题是：

> 独居老人一个人生活时，容易出现三餐不规律、饮食单一、出门购物不方便、子女无法及时了解老人状态等问题。

福伴机器人通过语音式交互，帮助老人按时吃饭、合理搭配饮食、规划更适合老人的购物路线，并将老人每日饮食和出行情况同步给子女，让老人生活更方便，也让子女更放心。

## 目标用户

### 使用者：独居/空巢老人

典型用户为 65–80 岁、基本生活能自理，但存在饮食不规律、腿脚不便、出门购物不方便等问题的独居或空巢老人。

示例用户：

> 张国华，76 岁，独居老人，有高血压，腿脚不太方便。平时能自己做饭、买菜，但经常早餐随便吃、午餐吃面条、晚餐喝粥配咸菜。出门买东西时，他担心走远、迷路、路不好走，也不知道哪里东西更便宜。

### 购买者：成年子女

典型购买者为 35–50 岁、工作繁忙、无法长期陪伴父母的成年子女。

示例用户：

> 张敏，39 岁，张国华的女儿，在外地工作。她担心父亲一个人在家不好好吃饭，也担心父亲出门买菜走太远或遇到突发情况没人知道。她希望每天收到父亲的饮食和出行摘要。

## 核心功能

### 1. 三餐饮食管家

福伴机器人会在早、中、晚三个时间段提醒老人吃饭、喝水，并通过语音记录老人吃了什么。

主要功能包括：

* 三餐提醒；
* 喝水提醒；
* 饮食语音记录；
* 饮食结构判断；
* 适老化饮食建议；
* 每日饮食摘要。

示例：

> 老人：小福，我中午吃了白粥和咸菜。
> 小福：可以的，不过这顿菜和蛋白少了点。晚上要是方便，加个鸡蛋和一份青菜，身体更有劲儿。

---

### 2. 老年购物导航

老人可以直接告诉小福自己想买什么，小福会识别购物需求，并推荐附近更适合老人前往的门店。

主要功能包括：

* 购物需求识别；
* 自动生成购物清单；
* 附近超市/菜市场/药店搜索；
* 商品价格与折扣信息展示；
* 门店推荐；
* 推荐理由说明。

示例：

> 老人：小福，我想买鸡蛋和青菜，哪里合适？
> 小福：我帮您看了。幸福超市离家 500 米，路平一些，鸡蛋也有折扣。菜市场虽然便宜一点，但要走得远。今天咱们去幸福超市更稳妥，不急，我陪您慢慢来。

---

### 3. 健康友好路线规划

路线规划不是只看最近或最快，而是结合老人的身体状况，优先推荐近一点、平一点、少台阶、少复杂路口的路线。

考虑因素包括：

* 老人腿脚情况；
* 路线距离；
* 是否有台阶；
* 是否需要过复杂路口；
* 是否为老人熟悉路线；
* 天气情况；
* 是否适合当天出门。

推荐原则：

> 不是最便宜，也不是最近，而是最适合老人今天出门。

---

### 4. 家属安心反馈

子女端可以查看老人每日饮食、购物和出行摘要，减少对子女的信息盲区。

主要功能包括：

* 今日饮食摘要；
* 今日购物摘要；
* 今日出行摘要；
* 关怀建议；
* 一键电话关心。

示例摘要：

> 父亲今日三餐基本正常，午餐蔬菜偏少，系统已提醒晚餐补充青菜。下午计划前往幸福超市购买鸡蛋和青菜，推荐路线较近且平稳。今日无需紧急处理，建议晚上电话关心一下。

## 机器人角色设定

### 角色名字

**小福**

### 身份定位

**独居老人身边的健康生活陪伴员**

### 性格关键词

* 稳当；
* 贴心；
* 耐心；
* 会过日子；
* 懂分寸；
* 有人情味。

### 标志性口头禅

> 不急，我陪您慢慢来。

### 语言风格

小福的语言风格要求：

* 不使用复杂医学术语；
* 不制造焦虑；
* 不命令老人；
* 多使用“咱们”“您”“慢慢来”“我帮您看看”等表达；
* 语气像家人，而不是冷冰冰的客服；
* 不说“健康指数异常”“检测异常”等容易吓到老人的词。

## 推荐逻辑说明

本 Demo 中的门店推荐不只看商品价格，而是综合考虑老人实际情况。

### 推荐因素

| 因素     | 说明                |
| ------ | ----------------- |
| 距离     | 距离越近越适合老人         |
| 路线安全   | 少台阶、少复杂路口、路面平整优先  |
| 商品价格   | 价格较低可加分           |
| 折扣情况   | 有折扣可加分            |
| 老人身体状况 | 腿脚不便时，路线安全权重更高    |
| 熟悉程度   | 老人常去的门店优先         |
| 天气情况   | 天气炎热、下雨时，不建议远距离出门 |

### 示例推荐结果

推荐门店：**幸福超市**

推荐理由：

> 幸福超市距离张爷爷家约 500 米，预计步行 8 分钟，路线平稳，只需经过一个小路口。虽然南门菜市场价格更低，但距离较远，需要经过两个复杂路口。考虑到张爷爷腿脚不太方便，今天更推荐去幸福超市。

## 项目边界说明

本项目是一个面向居家养老场景的 AI 健康生活陪伴 Demo，不属于医疗诊断系统。

### 本项目可以做

* 辅助饮食提醒；
* 辅助购物推荐；
* 辅助路线规划；
* 家属关怀反馈；
* 居家养老生活陪伴。

### 本项目不做

* 不诊断疾病；
* 不治疗疾病；
* 不保证老人绝对安全；
* 不承诺全网最低价；
* 不替代医生；
* 不替代护理人员；
* 不替代子女照护。

## 项目亮点

### 1. 不只是提醒吃饭

福伴机器人不仅提醒老人按时吃饭，还会根据老人饮食记录给出温和、可执行的饮食建议。

### 2. 不只是普通导航

普通地图只告诉老人怎么走，福伴会先判断老人适不适合走，并结合身体状况推荐更稳妥的路线。

### 3. 不只是找最低价

普通购物软件更关注价格，福伴机器人会综合价格、距离、路线难度和老人身体情况，推荐更适合老人的购买地点。

### 4. 不只是陪老人，也让子女放心

福伴机器人会把老人每日饮食和出行情況整理给子女，帮助子女及时了解父母生活状态。
