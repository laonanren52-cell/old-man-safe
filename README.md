# 小满 AI 健康生活陪伴机器人

这是一个面向项目汇报、比赛答辩和 Demo 演示的 React + TypeScript 前端项目。小满面向独居/空巢老人，围绕三餐生成、饭后反馈、购物路线、家属日报和老人档案，展示“陪老人吃好三餐，规划安心购物路线，让子女每天更放心”的产品价值。

## 启动

```bash
npm install
npm run dev
```

## 构建

```bash
npm run typecheck
npm run build
```

## 页面

- 今日总览
- 三餐生成
- 饭后反馈
- 购物导航
- 家属日报
- 老人档案

## API 预留

`src/services` 中预留了统一 `apiClient` 以及三餐、反馈、路线、家属、天气上下文接口。当前没有真实后端时会自动使用 mock 数据兜底。

本项目仅演示生活照护提醒、购物路线辅助和家属关怀反馈，不作为医疗或护理服务。
